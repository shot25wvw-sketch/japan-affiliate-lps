The Toyama Casting Tradition

NOUSAKU is a casting manufacturer in Takaoka, Toyama, continuing techniques used for centuries in Japanese metalwork.

Casting a furin in tin rather than blowing it in glass is a different craft tradition entirely - the result is a quieter, more architectural object that still carries the same seasonal meaning.
